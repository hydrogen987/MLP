02 / 参数手册

八个旋钮，决定网络学成什么样

每个参数都在改变同一件事：参数更新的方向与步长，或者模型能表达的函数复杂度。读完后可以直接载入对应实验。

01优化

学习率 η · learning rate

每次参数更新迈出的步子。梯度只告诉你「往哪走」，学习率决定「走多远」。过大会一步跨过谷底、来回震荡；过小则收敛极慢，看起来像没在学。

θ ← θ − η · ∂L/∂θ

观察把 η 从 0.001 一路调到 8，看损失曲线先变陡，最后在 0.6 附近来回跳动。

02容量

隐藏层与宽度 depth · width

层数决定非线性变换叠加的次数，宽度决定每层能容纳多少个特征检测器。0 个隐藏层等价于逻辑回归，只能画一条直线；1–2 层足以应付本页大多数二维数据。

h⁽ˡ⁾ = f(W⁽ˡ⁾h⁽ˡ⁻¹⁾ + b⁽ˡ⁾)

观察把层数切到 0，圆环数据集会立刻变成一条直线切开的样子。

03非线性

激活函数 activation

没有它，多层线性变换仍然等价于一层。ReLU 计算快、正半轴不饱和；Tanh 输出零中心、曲线平滑；Sigmoid 两端饱和，深层容易梯度消失；LeakyReLU 给负半轴留了一条小缝。

ReLU(z) = max(0, z) · Tanh(z) = (eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)

观察把激活函数换成 Sigmoid，再把隐藏层加到 3 层，训练明显变慢。

04随机性

批大小 batch size

一次参数更新使用多少个样本。小批量引入梯度噪声，曲线更抖，但常带来更好的泛化；大批量梯度更准、每轮更新次数更少。批大小为 1 就是纯随机梯度下降。

g = (1/B) Σᵢ ∇L(xᵢ)

观察把批大小从 64 调到 1，损失曲线会从平滑变得毛糙。

05优化

优化器 optimizer

SGD 只看当前梯度；Momentum 累积速度，能冲过平坦区；RMSProp 按梯度平方缩放每个参数的学习率；Adam 结合两者并做偏差修正，通常收敛最快，但也可能在小数据上过拟合。

Adam: m̂ / (√v̂ + ε) 代替原始梯度

观察在对照实验里同时训练四个优化器，比较损失曲线分叉的早晚。

06正则

L2 正则 weight decay

在损失里加上 λ/2·‖W‖²，等价于每次更新都把权重往 0 拉一点。它抑制过大的权重，让决策边界更平滑。λ 太大会让网络欠拟合，边界变得过于保守。

L = LCE + (λ/2) Σ ‖W‖²

观察在过拟合实验里把 λ 从 0 调到 0.05，边界的小岛会被抹平。

07起点

初始化 initialization

权重初始值决定训练的起点。He 初始化适配 ReLU，Xavier 适配 Tanh。如果全部初始化为 0，同一层的神经元梯度完全相同，对称性永远无法打破——网络什么也学不到。

He: σ = √(2/nin) · Xavier: σ = √(2/(nin+nout))

观察选择「全零」初始化，损失会一直停在 ln 2 ≈ 0.693。

08泛化

轮数与数据 epochs · data

一个 epoch 表示完整遍历一次训练集。训练损失下降但测试准确率停滞，通常意味着过拟合；两者都高但损失不降，可能是学习率或容量不合适。噪声越大，越需要正则化。

gap = acctrain − acctest

观察关注「训练 / 测试准确率」两个数字的差距，而不只是损失。

04 / 对照实验

一次只改一个参数

同一个数据集、同一套网络，只改变一个变量，让四条损失曲线在同一个坐标系里分叉。这是理解超参数最直接的方式。

扫描参数
使用当前数据集 · 160 轮

每组的训练轮数、初始化和数据完全相同；结束后在卡片中给出训练 / 测试准确率。曲线越早下降并保持平稳，说明该设置越有效。

05 / 实现原理

六行公式，一个反向传播

页面里的每一块颜色都来自下面这些计算——没有框架、没有预训练权重，只有矩阵乘法、链式法则和一块画布。

前向传播
a(l) = f( W(l) a(l−1) + b(l) )

每一层先做仿射变换，再过激活函数。最后一层的标量输出经过 sigmoid，解释为 p(y = 1)。

损失函数
L = −(1/N) Σ [ y ln p + (1−y) ln(1−p) ] + (λ/2) Σ ‖W‖²

二元交叉熵衡量预测概率与标签的差距，第二项是可选 L2 正则。

输出层误差
δ(L) = p − y

sigmoid 与交叉熵的导数恰好抵消，得到这个干净的形式——也是代码里唯一没有显式求导的地方。

误差反传
δ(l) = ( (W(l+1))T δ(l+1) ) ⊙ f′(z(l))

把后一层的误差按权重加权传回来，再乘上本层激活函数的导数，这就是链式法则。

梯度
∂L/∂W(l) = δ(l) (a(l−1))T    ∂L/∂b(l) = δ(l)

梯度就是「本层误差 × 上一层激活」，一个外积就完成了整层权重的更新方向。

参数更新
θ ← θ − η · (g + λθ)   |   Adam: θ ← θ − η · m̂ / (√v̂ + ε)

朴素 SGD 直接用梯度；Adam 再维护梯度的一阶矩与二阶矩，并做偏差修正。

network.js · backward() 
// 输出层：sigmoid + 交叉熵 ⇒ δ = p − y
deltas[L - 1] = new Float64Array([cache.p - y]);

for (let l = L - 1; l >= 0; l--) {
  const d = deltas[l];
  const aPrev = acts[l];

  // 1. 用本层误差累积 W、b 的梯度
  for (let i = 0; i < nOut; i++) {
    gB[i] += d[i];
    for (let j = 0; j < nIn; j++)
      gW[i * nIn + j] += d[i] * aPrev[j];
  }

  // 2. 把误差传回上一层，乘激活导数
  if (l > 0) {
    for (let j = 0; j < nIn; j++) {
      let s = 0;
      for (let i = 0; i < nOut; i++)
        s += W[i * nIn + j] * d[i];
      deltas[l - 1][j] =
        s * act.df(zs[l - 1][j], aPrev[j]);
    }
  }
}
